# 访客屏幕共享

1. 管理员在电脑 Chrome 或 Edge 打开 HTTPS 控制台，进入「屏幕共享」（`/shares`）。
2. 填写名称，点击「创建共享并生成密钥」。
3. 点击「选择屏幕并开始」，在浏览器弹窗中选择整个屏幕、窗口或标签页并确认。
4. 复制完整观看链接发给对方。访客在电脑或手机浏览器打开后自动验证密钥并播放，无需控制台账号。也可打开不带密钥的链接后手动输入密钥。
5. 保持共享页面打开。离开页面、关闭浏览器或点击浏览器的停止共享按钮都会停止画面传输。

后台可以更换密钥（留空自动生成，或输入 16–128 字符新密钥）、停止和删除共享。更换密钥立即断开原观看者，但保留当前屏幕采集；旧链接不能重新加入。停止共享会断开所有人并停止采集，重新开启自动生成新密钥。删除会移除记录并断开所有人。共享者离线时记录保留，访客会看到离线提示。

链接形如 `https://你的域名/share/<共享ID>#key=<观看密钥>`。HTTPS 加密网页和认证传输，WebRTC 加密媒体传输。密钥放在 URL 的 fragment 部分，不进入 HTTP 请求 URL 或 Referer；认证通过 POST 请求体提交。服务端以 SHA-256 验证密钥，并使用 AES-256-GCM 加密保存可供管理员复制的密钥。拥有完整链接的人即可观看，请只发给预期观看者；这不是对链接文字本身加密。

观看票据只能用一次，有效期 30 秒；停止、删除和密钥更换会同时撤销未使用票据。观看信令使用独立 `/share-ws`，不接入主机远控会话，不开放键鼠、终端、文件或剪贴板通道。

当前最多保留 50 个共享，每个共享同时最多 3 人观看，单次观看最长 4 小时，到期可重新打开有效链接。共享者分别向每位观众发送视频，观看人数增加会增加上行带宽和编码负载。当前共享仅传输画面，不传输声音。此入口共享浏览器所选画面，尚不支持直接为已接入的 Agent 主机生成观看链接。

发起共享仍需要浏览器支持 `getDisplayMedia`，必须使用 HTTPS 或本机 localhost。手机可观看；不承诺手机浏览器发起采集。FPS 和网络往返延迟显示在画面上方，悬浮层不拦截点击。延迟数值不等于从屏幕变化到观看者看到画面的完整延迟。

本地验证：`npm run test:shares`，使用隔离数据库和端口 19987/19988，以 Canvas 视频源验证真实 WebRTC 传输，不操作现有桌面。
