# 远程主机分享

手机或电脑以管理员身份登录控制台，在主机卡片点击「分享远程主机」，或进入 `/shares`。

1. 分享来源选「已接入的远程主机」，选择在线主机。
2. 填写名称和分享码（6–128 字符，留空自动随机生成），设置有效期（留空不限时）。
3. 选择「仅观看」或「允许控制」，创建后分别复制链接和分享码发给对方。
4. 对方无需账号，在手机或电脑打开链接，输入分享码即可连接。

远程分享不使用手机的屏幕采集能力，也不要求管理员保持分享管理页打开。被分享的 Agent 必须在线并支持 `remoteSharing`；旧客户端需要重新安装新版安装包。主机使用稳定设备 ID，正常重连后原分享可继续使用。

「仅观看」只接收画面；「允许控制」可点击、拖动、使用鼠标键盘和手机上的键盘面板。访客不获得后台、独立终端、文件或剪贴板工具通道。允许控制意味着可操作远程桌面上的应用，包括通过桌面打开系统终端；不能将其理解为操作系统沙箱。

管理员可修改分享权限、分享码、有效期，也可停止、重新开启或删除。权限修改会立即断开访客，并废弃尚未使用的票据；再次输入分享码后按新权限连接。更换分享码、停止、删除和到期也会断开访客，释放按键。重新开启已停止的分享会更换分享码。到期后续期会更换分享码，旧码不会恢复使用。权限修改不改变原到期时间。

每台主机同时最多接入 3 个分享访客，另可保留 1 个普通管理员会话。访客退出或撤销不会结束管理员的独立会话。多人控制时操作同一个桌面，鼠标和输入会互相影响。每位访客独立编码/传输画面，会增加主机 CPU 和上行带宽占用。无人观看时不为该分享采集桌面。单次访客连接最长 4 小时，之后可以重新使用仍有效的分享码连接。

## 有效期与认证

时间按当前设备时区输入，服务端持久化绝对到期时间，重启不会重新计时。到期立即拒绝新观看和票据认证，约 1 秒内关闭已有分享会话。

远程分享链接形如 `https://你的域名/share/<共享ID>`，不包含分享码。分享码通过 HTTPS POST 请求体提交，不进入请求 URL。服务端 SHA-256 验证分享码，AES-256-GCM 加密保存可供管理员复制的原码。短期票据有效 30 秒，仅使用一次，并绑定分享当前权限版本。媒体使用 WebRTC 加密传输。权限由服务端决定并发送给 Agent，Agent 在只读会话中拒绝所有输入和工具数据通道。

当前分享仅传输画面，不包含声音。FPS 和网络往返延迟显示在画面上，悬浮层不拦截点击；往返延迟不等于完整操作到显示延迟。

## 当前电脑的浏览器屏幕

仍可将分享来源切换为「当前电脑的浏览器屏幕」，在电脑 Chrome 或 Edge 的 HTTPS 页面选择屏幕、窗口或标签页。此模式只读，必须保持发布页面打开；手机不能用该模式采集远程主机。浏览器屏幕链接兼容包含 `#key=` 的自动认证链接，密钥不会进入 HTTP 请求 URL。

验证：`npm run test:remote-shares` 在独立 Xvfb 桌面验证手机尺寸后台创建、真实 Agent 画面和输入、权限变更、访客撤销与管理员会话隔离；`npm run test:shares` 验证原浏览器屏幕流程。
